# UI・UXの設計

Shift Builderは、シフト入力の手間を減らし、働いた成果を見返したくなる体験を目指す個人向けiOSアプリです。主対象はアルバイトをする学生・フリーター。掛け持ちの有無を問わず、自分の勤務と給与を確認するために使います。

## ホーム：稼ぎを見返したくなる

- 黒を基調にしたカードで、金額を大きく、勤務先別の内訳をまとめて表示。
- 支給月ベースの金額と勤務月ベースの収支を、カードの切り替えで確認。
- 収支の推移をグラフで表現し、数字の一覧だけでは把握しにくい変化を示す。
- 金額を隠すボタンを用意し、人前でも予定を確認しやすくする。
- 次のシフトをホームに置き、勤務の確認につなげる。

UIは [ContentView.swift](../ShiftManagerApp/ShiftManagerApp/ContentView.swift) に実装しています。

## 給料日：成果の確認から記録へ

勤務先ごとの給料日に、コインの回転とバナーの表示アニメーションで知らせます。「入力する」から実際の手取り額を残せるため、給料日の演出を記録のきっかけにできます。

締め日・支払日・休日の調整条件を使って表示日を判断し、その給料日の実績を入力したらバナーを表示しません。表示される給与見込みと、本人が入力した実際の手取りは区別します。

![実際の給料日アニメーション](screenshots/payday.gif)

実装は `ContentView.swift` の `pendingPaydays`、`PaydayBanner`、`ActualPaySheet` です。

## テンプレート：毎回の入力を減らす

登録した勤務から最近のパターンを表示します。日付を選んでテンプレートをタップすれば、勤務先・時間・時給・休憩などを引き継いだ勤務を追加できます。

- 履歴からパターンを作り、別のテンプレート一覧を管理する負担を減らす。
- 最近のパターンを最大5件表示し、使わないものは非表示にできる。
- 同じ日に追加済みのパターンはチェック表示にする。
- 追加時には触覚フィードバックを出す。
- 繰り返した先の日付の法定休日設定は、元の勤務からそのまま引き継がない。

実装は [ShiftsTab.swift](../ShiftManagerApp/ShiftManagerApp/ShiftsTab.swift) の `recentFormats`、`quickAdd`、`formatChip` です。

## 次の確認

上記は設計の意図で、利用者のモチベーションや継続率が改善した実績を示すものではありません。まず実際の画面・動きを見せ、テンプレート追加を試してもらい、今の管理方法から切り替えたい理由、入力で迷う場所、自分の次のシフトで試したいかを確認します。

試用できた場合は、初回以外にも自分から開くか、テンプレートを再利用するか、今の方法を置き換えるかを確かめます。[製品の方針](PRODUCT_DECISION.md) と [検証範囲](VALIDATION.md) も参照してください。
