# 公開ソースとローカルデモのデータ

このリポジトリは開発実績として公開したソースです。App Storeで提供中のサービスではありません。

`ShiftManagerApp-LocalDevice` のデモはFirebaseを初期化せず、入力した記録を端末内のUserDefaultsに保存します。写真の文字認識はApple Visionによる端末内処理で、画像とOCR文字列をクラウドへアップロードしません。確認して登録したシフトだけを保存します。ローカルのStoreKit購入テストでは実際の料金は発生しません。

通常構成は、各自が設定したFirebaseの認証とFirestoreを使用します。実際のサービスとして配信する場合は、提供者がデータの扱いと連絡先を定め、サービス用のプライバシーポリシーを用意する必要があります。
