# 公開ソースとローカルデモのデータ

このリポジトリは開発実績として公開したソースです。App Storeで提供中のサービスではありません。

`ShiftManagerApp-LocalDevice` のデモはFirebaseを初期化せず、入力した勤務先・シフト・給与などの記録を端末内のUserDefaultsに保存します。給与明細の課税支給額と、任意の手取り額は別の値です。年収の上限は端末に保存し、アカウントのデータ消去時に消します。現在の通常画面には、写真登録・課金・残高予測への入口はありません。

以前の写真認識の試作はApple Visionによる端末内処理で、画像とOCR文字列をクラウドへアップロードしません。以前のStoreKit購入テストはローカルテスト用です。これらの試作ソースが残っていることは、現行の通常画面で利用できることを意味しません。

通常構成は、各自が設定したFirebaseの認証とFirestoreを使用し、アカウント単位で勤務・給与などの記録を同期します。実際のサービスとして配信する場合は、提供者がデータの扱いと連絡先を定め、サービス用のプライバシーポリシーを用意する必要があります。
