# 市場調査と開発の判断

2026-10-06時点。主対象は、掛け持ちを含むアルバイト学生・フリーター本人です。基本無料に加えて、90日先の残高予測、収入比較、写真からの一括登録を月額Plusの候補として実装しました。月300円は価格仮説で、販売実績はありません。

## 確認できたこと

- シフトボードは2025年12月時点で累計1,200万ダウンロードを公表しています。シフト・給与管理への需要があることの材料ですが、このアプリへの需要や有料需要を証明する数字ではありません。[公式サイト](https://shiftboard.jp/)
- シフトボードは無料で、複数勤務先・給与計算・収入計画を提供しています。[App Store](https://apps.apple.com/jp/app/id747364886)
- Shiftalyzeは写真からのシフト読み取りと無料枠、PRO月額400円を掲載しています。2026年6月20日の更新履歴には無料OCRを月3回に変更した記載があります。説明文には広告利用の古い記載も残っており、現行の回数や精度はアプリで未確認です。[App Store](https://apps.apple.com/jp/app/id6760759041)

上記は公開された製品情報です。競合の購入者数・売上・読み取り精度は調査で確認できていません。古いApp Storeレビューにある要望を、現在も未解決の課題とは扱いません。

## 判断

市場の存在だけで収益化を前提にできません。無料の代替がある中で、このアプリに切り替える理由、毎月支払う理由、継続、利用者を見つける方法が未確認です。写真取り込み自体も独自性の根拠にはできません。

まず年間約12,000円の費用回収を仮の目標とすると、月300円の商品からの入金を保守的に月200円と置いた場合、60回の月額課金が必要です。例は5人が12か月、10人が6か月。運営費と開発時間を含めた利益は別で、これは実績や予測ではなく仮定による計算です。[日本のApple手数料](https://developer.apple.com/jp/support/app-distribution-in-japan)

収益目的の追加開発を止め、ソース・画面・設計・検証結果を開発実績として公開します。再開する場合は、利用者の現在の作業、実際の時間削減、次のシフト更新での利用、購入と更新の実績を確認します。聞き取りは未実施で、試用希望・購入・売上を作り上げません。
