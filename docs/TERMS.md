# 開発版の利用について

更新日：2026年10月17日

このリポジトリは開発・検証用のソースです。App Storeで配信中のサービスを案内するものではありません。ここではアプリを動かしたときの表示と記録の扱いを説明します。

- テンプレートは日付なしの勤務パターンとして保存します。作成だけでは実際の勤務や給与予定に加えません。テンプレートと実際の勤務の削除は別々に行います。
- 「来月の給与予定」は、入力済みのシフトと勤務先の締め日・給料日などから計算した控除前の見込みです。実際の振込額の確認には給与明細と勤務先の案内を使用してください。
- 年収の表示は、給与明細から入力した課税支給額を支給年で合計し、自分で設定した上限までの差を表示します。シフトの見込みや手取りだけの記録は自動で含めません。税金・扶養・社会保険の適用や加入可否を、この表示だけで自動判定しません。
- 現在の通常画面にはサブスクリプションの申し込み、写真からの登録、残高予測はありません。
- シフト削除はすぐに反映し、最後の削除から5秒間のみ元に戻せます。期限内でもログアウト・アプリ終了で復元候補が失われます。
- ローカルテスト版の記録はその端末内に保存します。通常版では自分のアカウントとFirebase環境を使用し、未送信の変更がある場合は同期を終えてからログアウトしてください。アカウント削除が完了した後の記録はアプリから復元できません。
- 他人のアカウントや記録への不正アクセス、認証情報の不正取得、サービスの妨害を行わないでください。

情報の扱いは [PRIVACY.md](PRIVACY.md) を確認してください。自分のサービスとして配信する場合は、運営者・問い合わせ先・提供条件を定めて各リンクを差し替えてください。公開Issueへの報告には、パスワード・認証コード・実際の給与明細などの個人情報を含めないでください。
